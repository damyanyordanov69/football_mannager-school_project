# ⚽ Система за управление на футболни първенства (Football Manager)

## 📖 1. Описание на проекта
Проектът представлява десктоп приложение (Windows Forms) за цялостно управление на футболни отбори, играчи, трансфери, лиги, генериране на мачове и автоматично изчисляване на класиране. Системата поддържа пълна история на събитията (голове, картони) и е изградена върху релационна база данни.

## 🛠 2. Използвани технологии
* **Език за програмиране:** C# (.NET Framework / .NET Core)
* **Потребителски интерфейс:** Windows Forms (WinForms)
* **База данни:** MySQL (XAMPP / phpMyAdmin)
* **Връзка с базата:** Библиотека `MySql.Data` (ADO.NET)
* **Контрол на версиите:** Git & GitHub

## 🏗 3. Архитектура на приложението
Проектът стриктно следва **Трислойна архитектура (Three-Tier Architecture)**, съчетана с **Шаблон Хранилище (Repository Pattern)**, за да гарантира чисто разделяне на отговорностите:
1. **Слой на данните (Data Layer):** MySQL база данни, която съхранява информацията и следи за нейната цялост чрез Primary/Foreign keys, UNIQUE ограничения и `ON DELETE CASCADE`.
2. **Слой с бизнес логика (Business/Repository Layer):** Класовете в папка `Repositories`. Те извършват CRUD операциите, обработват бизнес логиката (напр. алгоритми за генериране на кръгове) и комуникират с базата данни чрез защитени параметризирани SQL заявки (за предпазване от SQL Injection).
3. **Представителен слой (Presentation/UI Layer):** Файлът `Form1.cs`. Той отговаря единствено за визуализацията (DataGridView, ComboBox) и приемането на входни данни от потребителя. Не съдържа директни SQL заявки.

## 🗄 4. Структура на Базата данни (Схема)
Базата данни `football_manager` съдържа 7 свързани таблици:
* `Teams` (team_id, name, city) - Съхранява футболните клубове.
* `Players` (player_id, first_name, last_name, birth_date, position, team_id) - Играчи и връзката им към текущ отбор.
* `Transfers` (transfer_id, player_id, from_team_id, to_team_id, fee, date) - История на трансферите.
* `Leagues` (league_id, name, season) - Информация за първенствата.
* `league_teams` (league_id, team_id) - Свързваща таблица (Many-to-Many), показваща кои отбори в кои лиги участват.
* `Matches` (match_id, league_id, round_no, home_team, away_team, scores, date, stadium) - Програма на мачовете и крайни резултати.
* `MatchEvents` (event_id, match_id, player_id, team_id, minute, type) - Събития в мача (Гол, Жълт/Червен картон, Фал).

## 🚀 5. Реализирани функционалности
* **Отбори и Играчи:** Пълен CRUD (Създаване, четене, редакция, изтриване) за клубове и техните футболисти.
* **Търсене и Филтрация:** Търсене на играчи по име, позиция и отбор в реално време.
* **Трансфери:** Запис на трансферна история. Използвана е **базово-данна транзакция (Transaction)** за атомарно обновяване на таблиците `Transfers` и `Players`. Включена е валидация "не към същия клуб".
* **Лиги и Участници:** Управление на първенства. Имплементирана е връзка **Много-към-много**. Добавяне/Премахване на свободни клубове в избрана лига. 
* **Програма и Мачове:** **Round-Robin алгоритъм** за автоматично генериране на първенство по кръгове. Опция за 1 полусезон или 2 (разменено гостуване). 
* **Събития в мача:** Записване на минута, играч и тип събитие (Голове, Картони). Падащото меню филтрира играчите само от двата отбора на терена. Имплементирано е **автоматично изчисляване на резултата** въз основа на въведените голове.
* **Класиране:** Автоматично изчисляване на статистика (Победи, Равни, Загуби, Голова разлика, Точки) на база изиграни мачове. Сортиране по точки, голова разлика и отбелязани голове.

## 💻 6. Инструкции за стартиране (Deployment)
1. **База данни:**
   * Отворете phpMyAdmin (през XAMPP).
   * Създайте база данни с име `football_manager`.
   * Изпълнете кода от файла `schema.sql` (за създаване на таблиците).
   * Изпълнете кода от файла `seed.sql` (за зареждане на примерни данни).
2. **Настройка на връзката:**
   * Отворете проекта във Visual Studio.
   * Уверете се, че библиотеката `MySql.Data` е инсталирана (през NuGet Package Manager).
   * В случай на нужда, обновете паролата в `Db.cs` (по подразбиране `uid=root;pwd=;`).
3. **Стартиране:** Натиснете бутона `Start` във Visual Studio. Приложението е готово за работа!
